## Как работают автотесты

1. **Получение токена:**
   ```java
   String jwtToken = getJwtToken(); // POST /api/v1/auth/login
   ```

2. **Выполнение авторизованного запроса:**
   ```java
   mockMvc.perform(get("/api/v1/project")
       .header("Authorization", "Bearer " + jwtToken))
       .andExpect(status().isOk())
       .andExpect(jsonPath("$").isArray());
   ```

3. **Проверка ответов:**
   - HTTP статус коды (200, 201, 400, 401, 403)
   - Структура JSON (jsonPath)
   - Валидация данных
   - Безопасность (требование токена)

## Запуск автотестов

```bash
# Только автотесты (без ручных)
./gradlew testAuto

# Все тесты
./gradlew test

# Конкретный тест
./gradlew test --tests ProjectRestControllerTest
```

## Что проверяют автотесты

### Безопасность
- ✅ Все API endpoints требуют JWT токен (кроме login)
- ✅ Без токена возвращается 401 Unauthorized
- ✅ С валидным токеном запросы проходят

### Валидация
- ✅ Пустые обязательные поля -> 400 Bad Request
- ✅ Неверные данные -> соответствующие ошибки
- ✅ Валидные данные -> успешное создание/обновление

### Структура ответов
- ✅ Правильные HTTP статусы (200, 201, 400, 401, 403)
- ✅ JSON структура соответствует ожидаемой
- ✅ Создание возвращает 201 Created с данными сущности
