# Руководство по ручным тестам

## 📋 Обзор

В проекте создан набор ручных тестов для проверки функциональности приложения. Ручные тесты требуют визуальной проверки и ручного выполнения действий.

## 🚀 Запуск ручных тестов

### Через Gradle

```bash
# Запустить только ручные тесты
./gradlew testManual

# Запустить все тесты (включая ручные)
./gradlew testAll

# Запустить только автотесты (без ручных)
./gradlew testAuto
```

### Через IDE

1. Откройте проект в IntelliJ IDEA
2. Найдите классы с аннотацией `@ManualTest`
3. Запустите нужный тест

## 📁 Структура ручных тестов

```
src/test/java/com/petralib/test/manual/
├── ManualLoginTest.java          # Тесты аутентификации (MT001-MT004)
```

## ✅ Как выполнять ручные тесты

1. **Запустите приложение:**
   ```bash
   ./gradlew bootRun
   ```

2. **Запустите ручной тест:**
   ```bash
   ./gradlew testManual --tests ManualLoginTest.testLoginViaUI
   ```

3. **Следуйте инструкциям:**
   - Тест выведет в консоль подробные инструкции
   - Выполните действия, указанные в инструкциях
   - Проверьте все пункты из списка "✅ ПРОВЕРЬТЕ"

4. **Зафиксируйте результаты:**
   - Отметьте, какие проверки прошли успешно
   - Запишите найденные проблемы
   - Создайте issue для найденных багов

## 📊 Отчетность
